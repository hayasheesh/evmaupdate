## 原因

`GLOBAL_BALANCE_REWARD_MODE` が違う。

- hobo100100: 帯のステップ関数（帯の中なら +1、外は `1 - (2/D)(d-D)` で線形、下は無限）
- run A / B: `bounded_absolute_error` = `1 - 2*tanh(d/150)`、値域 ±1

bounded は帯の中にいても満点が出ない（偏差 50 kW で +0.36、100 kW で −0.17）。
そのため 1 ステップ報酬が +0.25 前後で頭打ちになり、`Q/global` が
`1/(1-0.95)=20` の 4 分の 1 の 5 付近で止まる。実測 5.15 と一致。
hobo は報酬が +0.99 に飽和して Q が 19.9 に達した。

入札バンクの帯幅は tracking 有効ステップで中央 108.9 kW（min 25.0 / max 260.5、
ゼロなし、tracking 有効は 82.6%）。hobo の固定 150 kW と同じ桁なので帯は原因ではない。
