## 2　評価の環境

ひな形の方法にある「実際の状況の難しさ」は、次の3つで作る。

- 前日には当日の指令が分からない。入札器は、過去の実指令から引いた設計用の指令128本を使う［コード確認］
- EVは分布だけが分かる。EVの到着と出発、初期SoC、目標SoCは各局の実セッションから引く。入札器は、128通りのEVの実現から選んだ3通りを使う［コード確認］。この分布の予測の精度は、5分ごとの接続台数で約91%である（測り方は[EVデータ](EVデータ.md)の「予測の精度」）［実測］
- 出発するEVのSoCは、目標（上限80%）に必ず届ける

| 項目 | 値 |
|---|---|
| 局 | 6 station（職場3・住宅3）と20 station（職場10・住宅10） |
| EVの定格 | 全EV 7.7 kW |
| 入札日 | 平日だけ |
| 最低入札量と余裕 | 6 station 70 kW・7 kW、20 station 250 kW・25 kW（どちらも仮の値） |
| 指令 | AEMOとERCOTの計画からのずれ。PJM RegDは学習中 |
| 評価の組 | 検証用の平日5日×評価用の指令4本×EVの乱数2通り＝40組 |
| 合否 | 30分コマの1分値30点のうち27点が「指令量±約定量の10%」に入れば合格。同じリソースで月3回不適合になると、新規取引を停止されうる（取引規程 本則 第41条）［外部一次資料］ |

シミュレーションは5分刻みである。5分の時刻を1つ外すと、1分値で5点を外す。そのため、5分を1つでも外したコマは不合格になる。

平均誤差率は、約定量に対する平均の絶対誤差の比である。不合格のコマが1日に0.6〜1.0コマあると、月3回の不適合に3〜5日で届く［計算］。

SoC達成率が大きく下がったのは、指令が長い時間一方向に偏った回である。本研究の入札とLiu/Lyuの配分では、AEMOの2024-02-01の指令3がその例だった。この指令は、基準の電力より充電を減らす向きに合計−380 kWh偏っていた。SoC達成率は、EVの乱数2通りで47%と57%だった［実測］。Liu/Lyuの計画は、電池残量を指令の分布の期待値で進める［コード確認］。設計用の指令の平均はほぼ0なので、偏りを見込めない。

測ったのは5日分で、日の数を増やした検証と信頼区間はまだない（実験A2）。

### 4.3　性能が落ちる5つの原因と、その影響（要旨の結果3）

ひな形の5つの原因ごとに、今ある測定と、影響の大きさを測る実験を並べる。影響の大きさは、その原因だけを外したときに増える「1日すべて満たした組」と、30分コマの合格率で測る。

**原因1：指令が分からない**

- 今ある値：設計用の指令を128本から256本に増やしても、6 stationと20 stationの未見通過率はほぼ変わらなかった（下の表）［実測］。旧条件の7 stationでは、256本にすると成り立たない割合が3.62%から1.39%に下がった［実測、10/5〜10/6］
- 当日の指令を前日に知っても、入札量は本線の1.04〜1.07倍にとどまった（4.2節）［実測］
- 足す実験：C1（先の指令を知るルールベースとMARLの合格率）

**原因2：EVが分からない**

- 今ある値：EVの実現の選び方を変えると、未見通過率と入札量が変わる（下の表）［実測］。6 stationでSoCの需要の最小・中央・最大を選ぶと、入札量は16〜17%増え、未見通過率は3〜5ポイント下がった。20 stationでは、入札量の増加は4%で、未見通過率はほぼ同じだった
- 当日のEVを前日に知ると、入札量は本線の1.38〜1.41倍になった（4.2節）［実測］。指令とEVの両方を知る上限（1.42〜1.46倍）に近い
- 足す実験：C2（先のEVを知るルールベースの合格率、実験B2）

**日本の二次②**：同じリソースで月3回不適合になると、新規取引を停止されうる。平日だけ入札し、1日48コマに入札すると、月のコマは960前後になる。停止を避けるには、コマの合格率を99.69%以上に保つ必要がある［計算］。どの方法も届いていない。最も高い20 station AEMOの中央のルールベースでも、月に12回前後の不適合になる。

**デンマークのP90**：Energinetは、入札時点の予測した容量を90%以上の時間で出せることを求める（Prequalification v2.1.3 §10.2.2）［外部一次資料］。本研究では、5分ごとの合格率を当てる。評価期間を通した値で見ると、中央のルールベースとLiu/Lyuは97〜99.5%で、基準を満たす。分散MARLは、AEMOが90.2%（6 station）と93.1%（20 station）で基準を超え、ERCOTは81.8%と86.4%で届いていない。日ごとに見ると、AEMOのMARLでも40日のうち10〜15日は90%を下回る。
