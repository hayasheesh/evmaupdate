# 精度要求の規定：日本の条文と海外市場

入札器が置いている許容幅の仮定を、どこまでが条文でどこからが仮定か分かる形で残す。

## 日本（二次調整力②）

取引規程別冊の確認済みの部分。

| 項目 | 規定 |
|---|---|
| 許容範囲 | 指令量 ± 当該30分コマのΔkW約定量 × 10% |
| 判定の粒度 | 1分値 |
| 合格条件 | 30分コマ30点のうち27点（90%）以上が帯内（取引規程 第39条(3)） |
| 猶予 | 月3日まで不適合を許す |
| 指令間隔 | 簡易指令システムで5分。専用線は数秒〜数分 |
| 応動・継続 | 応動5分以内、継続30分 |
| 指令なし | 直近の指令を継続する。指令量ゼロなら基準値 ± 約定量 × 10% |
| 最低入札量 | 簡易指令システム1 MW、専用線5 MW。刻みは1 kW |

三次②は30分平均で判定するので、アセスメントIIの判定方法が違う。OCCTOの委員会資料でよく引かれるものは三次②の話なので、判定方法をそこから読まない。

許容幅は約定量の10%なので、入札を小さくすると帯も狭くなる。小さい入札が楽な入札とは限らない。

**実装の最低入札量（7 stationで250 kW、20 stationで800 kW）は、市場の規定ではなく下位制御器の誤差から決めている。** 制御器の誤差より細い帯のコマに入札すると合格できないためで、決め方は[入札器の問題設定](入札器の問題設定.md)にある。
実物の 1 MW は絶対値で、局数に比例しない。7 局にそのまま当てると参加ブロックがゼロになり、入札器の挙動が何も観察できない。

この縮小は精度について保守側に倒れる。最低入札量で約定したときの帯は 250 kW なら ±25 kW、1 MW なら ±100 kW で、集約台数が増えても制御誤差は台数に比例しては増えないため、実物のほうが楽になる。規模だけの数値差なので、この点は論点にしない。

**上げと下げを同時に約定したとき、どちらの約定量を使うかは書かれていない。** いま上げしか商品がないので、書く必要がなかった。下げΔkWの調達はOCCTOで検討中で、同時約定時の算定式は確認できなかった。
入札器はこの穴を埋めるために仮定を置いている。[入札器の問題設定](入札器の問題設定.md)を参照。

## 海外：原文を確認したもの

| 市場 | 上下の扱い | 精度要求 |
|---|---|---|
| ドイツ aFRR | **方向ごとに別々**。事前審査の prequalifiable power も方向別に決まる | 事前審査は指令の ±5% に95%、±10% に5%。精算は Akzeptanzkanal（指令値に対する帯）で、帯の境界の絶対値の5%。未払いであって不適合ではない |
| CAISO | Reg Up と Reg Down が別商品 | 15分単位の精度を月平均。閾値は50% |
| PJM | **2025年10月に上下を1本の双方向商品へ統合** | 統合により「上下同時のときどちらの約定量か」という問い自体が消えた |

精算側の規定は、確認した範囲ではすべて方向別か指令値基準だった。上下の和を分母にする精算規定は見つかっていない。

## 海外：未確認

次の3件は他者の調査で挙がったもので、原文を当たっていない。

- 英国 Quick Reserve：不足供出は指令MWの95%以上、過剰供出は契約MWの120%以下
- フィンランド aFRR：発動量は指令量の90〜110%
- スイス aFRR：試験の最大出力と最小出力の差を \(P_{\mathrm{sek}}\) とし、その5%を帯とする

スイスの件だけは確認する価値がある。上下の和を基準にする唯一の事例で、これが事前審査であって精算でないなら、和を支持する実例はゼロになる。
